# PhotoAgent — 멀티에이전트 기반 AI 이미지 편집 플랫폼

## 1. 프로젝트 개요

포토샵과 유사한 웹 이미지 편집기를 직접 개발하고, 멀티에이전트 AI가 사용자의 요구에 따라 편집 방법을 제안하거나 직접 이미지를 수정하는 서비스.
사용자는 직접 편집할 수도 있고, AI의 도움을 받아 복잡한 이미지 편집을 간편하게 수행할 수도 있다.

## 2. 주요 기능

| 구분        | 기능                       |
| --------- | ------------------------ |
| 기본 편집     | 자르기, 회전, 크기 조절           |
| 이미지 보정    | 밝기, 대비, 채도, 색온도, 필터      |
| 고급 편집     | 레이어, 마스크, 브러시, 영역 선택     |
| AI 이미지 분석 | 인물·객체 인식, 영역 분할          |
| AI 편집 추천  | 이미지 분석 후 적절한 편집 방법 제안    |
| AI 자동 편집  | 자연어 요청에 따라 편집 도구 자동 실행   |
| AI 고급 편집  | 배경 제거, 객체 제거, 부분 보정      |
| 결과 관리     | 원본 비교, Undo/Redo, 이미지 저장 |

## 3. 서비스 이용 예시

사용자 요청: "인물은 밝게 하고 배경은 흐리게 만들어줘."

### 1) AI 추천 모드

AI가 분석하여 다음 작업을 제안
① 인물 영역 선택
② 인물 밝기 조절
③ 배경 블러 적용<br>
->사용자가 직접 작업

### 2) AI 자동 편집 모드
AI가 편집 엔진을 직접 호출
① 인물 마스크 생성
② 인물 밝기 자동 보정
③ 배경 블러 자동 적용<br>
->사용자는 결과를 추가 수정

## 4. 개발

1. 웹 이미지 편집기 구현 — 기본 편집, 색상 보정, 레이어, 마스크
2. 멀티에이전트 구축 — 이미지 분석, 작업 계획, 편집 추천
3. AI 자동 편집 구현 — 자체 편집 도구와 Tool Calling 연동
4. 고급 AI 기능 추가 — 인물 분리, 배경 제거, 객체 편집
5. 결과 검증 및 배포 — 편집 품질, 실행 시간, 비용 평가

## 5. 프로젝트 차별점

- 사용자와 AI의 협업: 사용자가 직접 수정하거나 AI에게 작업을 맡길 수 있음.
- 멀티에이전트 기반 편집: 이미지 분석부터 편집 계획, 실행, 결과 검증까지 역할 분담.
- 다양한 처리 엔진 통합: 브라우저, 컴퓨터 비전 모델, 외부 AI API를 상황에 따라 선택.
- 확장 가능한 구조: 새로운 편집 도구를 추가하면 AI가 해당 기능까지 활용하도록 확장 가능.

최종 목표: 단순한 AI 이미지 생성 사이트가 아닌, 전문 이미지 편집 기능과 멀티에이전트가 결합된 사용자-AI 협업형 웹 포토샵을 구현한다.
팀 프로젝트에서는 기본적인 편집기를 직접 구현하고, AI 추천 → 도구 자동 실행 → 결과 검증 → 사용자 추가 편집까지 완성하는 것을 1차 목표로 한다.
